# compiled-policy-c

Zero-dependency C library for deploying compiled tile policies on microcontrollers.

**Train with gradients, deploy with lookups.**

Works on ESP8266 (80KB RAM, 4MB flash), Arduino, STM32, and any platform with a C99 compiler.

## Features

- 🔑 **BLAKE2b-64 hashing** — compact ~200 LOC, no external crypto library
- ⚡ **O(1) hash table lookup** — FNV-1a bucketed table
- 🌡️ **Softmax selection** — configurable temperature for exploration
- 🪶 **Zero dependencies** — only `string.h`, `stdint.h`, `stdlib.h`
- 🎯 **Real policy data** — TTT policy compiled from [zeroclaw-arena](https://github.com/SuperInstance/zeroclaw-arena) tile compiler

## Quick Start

```bash
make test      # Run test suite
make bench     # Performance benchmarks
make examples  # TTT and C4 demos
```

## API

```c
#include "compiled_policy.h"

/* Hash a game state to 16 hex chars */
char hash[17];
policy_hash("X O X O  ", hash);

/* Look up best action */
int action = policy_lookup(&ttt_policy, hash);

/* Softmax selection from valid moves */
int valid[] = {0, 1, 3, 4, 6};
int selected = policy_select(&c4_policy, hash, valid, 5);
```

## Performance Targets

| Operation   | Target    | Typical (x86) |
|-------------|-----------|---------------|
| Hash        | < 500 ns  | ~200 ns       |
| Lookup      | < 100 ns  | ~30 ns        |
| Full decision| < 1 µs   | ~300 ns       |

## Memory

- Policy entry: 16 bytes (hash) + 4 (action) + 4 (score) = 24 bytes
- TTT policy: 56 entries × 24 bytes = ~1.3 KB
- C4 policy: 228 entries × 24 bytes = ~5.5 KB
- Hash table: 256 buckets (minimal overhead)
- Total RAM for TTT: **< 5 KB** — fits easily on ESP8266

## Cross-Compilation

```bash
# ESP8266
make esp8266 CC=xtensa-lx106-elf-gcc

# ARM Cortex-M
make arm CC=arm-none-eabi-gcc

# Arduino
# Copy compiled_policy.h + compiled_policy.c + policy header into your sketch
```

## Architecture

```
Game State (string)
       │
       ▼
  BLAKE2b-64 ──► 16 hex chars
       │
       ▼
  Hash Table (FNV-1a buckets)
       │
       ▼
  Policy Entry {hash, action, score}
       │
       ▼
  Softmax Selection (optional)
       │
       ▼
  Best Action
```

## Origin

Policy data generated by [zeroclaw-arena](https://github.com/SuperInstance/zeroclaw-arena) tile compiler experiment:
- Trained on 1000 games of tic-tac-toe
- 1644 tiles learned, 1174 compiled
- 81.2% win rate (compiled: 76.8%, within threshold)
